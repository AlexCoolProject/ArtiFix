Kaps FULL — Eseguibile Windows con licenza dedicata

Kaps FULL è la versione desktop eseguibile (.exe) pensata per un utilizzo locale e diretto sul tuo PC Windows. Ogni licenza viene emessa nel formato kaps.lic (firma crittografica Ed25519) ed è associata in modo univoco al Device ID del computer su cui attivi il software.

Come funziona Kaps FULL

Distribuzione tramite eseguibile .exe e attivazione tramite file di licenza kaps.lic.

💻

Eseguibile Windows (.exe)

Scarichi l'eseguibile Kaps.exe per Windows e lo avvii direttamente sul tuo dispositivo senza dipendere dalla sessione browser.

🆔

Vincolo al Device ID

Il file di licenza kaps.lic è generato specificamente per il Device ID del PC indicato durante l'ordine o l'attivazione.

🛡️

Firma crittografica Ed25519

Ogni file kaps.lic è firmato con chiave Ed25519 così da verificare l'autenticità della licenza e l'integrità dei dati associati al dispositivo.

⚡

Attivazione rapida

Una volta ottenuto kaps.lic, inserisci o carica il file nella cartella/finestra di attivazione di Kaps.exe sul dispositivo autorizzato.

Acquista Kaps FULL

Scegli il metodo di pagamento che preferisci: riceverai le istruzioni e il file di licenza kaps.lic legato al tuo Device ID.

1. Verifica e copia il tuo Device ID prima del pagamento

Apri Kaps.exe sul PC su cui intendi usare la licenza, copia il Device ID mostrato nell'applicazione e incollalo qui sotto per copiarlo o verificarne il formato prima di procedere al checkout.

Attivazione con Device ID e kaps.lic

Segui questi passaggi per installare l'eseguibile e attivare la licenza firmata Ed25519.

1

Ricava il Device ID

Avvia Kaps.exe sul PC Windows di destinazione e copia l'identificativo Device ID univoco del dispositivo.

2

Completa il pagamento

Paga tramite Stripe o PayPal e assicurati che il Device ID del computer sia associato alla tua richiesta di licenza.

3

Attiva con kaps.lic

Ricevi il file kaps.lic (firmato Ed25519 per quel Device ID) e applicalo in Kaps.exe per sbloccare la versione FULL.
